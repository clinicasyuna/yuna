Portal dos Acompanhantes - Sistema YUNA

1. Objetivo

Este manual ensina, de forma simples, como usar o portal para abrir e acompanhar solicitacoes.

2. Acesso rapido

  1. Abra o navegador (Google Chrome ou Microsoft Edge).
  2. Acesse: https://clinicasyuna.github.io/yuna/acompanhantes/
  3. Entre com e-mail e senha fornecidos pela equipe.

3. Como abrir uma solicitacao

  1. Clique no tipo de servico:
  • Manutencao
  • Higienizacao
  • Hotelaria
  1. Preencha as informacoes pedidas.
  2. Clique em Enviar solicitacao.

4. Como acompanhar sua solicitacao

No portal, voce consegue ver o status atualizado da sua solicitacao:

  • Pendente
  • Em andamento
  • Finalizada
  • Cancelada (com motivo informado pela equipe)

5. Avaliacao

Quando uma solicitacao for finalizada, voce pode avaliar o atendimento no proprio portal.

6. Se der erro para entrar

  • Use Esqueci minha senha.
  • Confirme se digitou e-mail e senha corretamente.
  • Atualize a pagina e tente novamente.

Resumo rapido

  1. Entrar no portal.
  2. Abrir solicitacao.
  3. Acompanhar status ate a finalizacao.
